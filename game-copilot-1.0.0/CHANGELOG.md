# 1.0.0 — 별도 신규 본체

- VS Code/PowerShell에서 실행하는 Python Tk 데스크톱 앱.
- run-free.ps1: NVIDIA, run-paid.ps1: OpenAI. 같은 프로필 / 별도 키·모델 설정.
- Qt와 외부 pip 의존성 제거. 기존 Python 실행 파일 경로 지정·기억.
- Windows DPAPI 키 저장과 지정한 이전 폴더의 .env 키 가져오기.
- 게임별 프로필 생성·이름 변경·삭제(휴지통)·복원, 목표·메모·판단 기록 저장.
- 관측/분석/실행 단계 로그, 경과시간, 호출수, 제공자 사용량 표시.
- 빠른 판단 → 필요한 경우 심화 1회. 무한 재시도와 무료→유료 전환 없음.
- 관측만/확인 실행/자동 실행. 허용된 구체적 행동 ID만 사용.
- 취소·중복 요청 차단·90초 지난 판단 차단·revision 재검증·확인 없는 재전송 금지.
- API 없는 규칙 기반 기지 데모 + 로컬 HTTP 브리지 샘플 + 연결 규격 문서.
- 무료/유료 동시 실행을 막는 데이터 파일 잠금.
