# Game Copilot 1.0.1 — 1번 연결 규격 패치

대상: 제공된 game-copilot-1.0.0. 이전 0.x나 다른 수정판에는 적용하지 마세요.
이 ZIP은 전체 설치본이 아니라 변경 파일만 들어 있는 덮어쓰기 패치입니다.

## 적용 순서

1. Game Copilot 창과 실행 중인 demo_bridge 서버를 종료합니다.
2. 기존 프로그램 폴더를 복사해 백업해 둡니다. 기존 폴더는 삭제하지 않습니다.
3. 패치 ZIP을 임시 폴더에 압축 해제합니다.
4. 압축 해제된 내용 전체(copilot 폴더, tests 폴더, 문서 등)를 기존 프로그램 폴더 안으로 복사합니다.
   대상은 run-free.cmd, run-paid.cmd, copilot 폴더가 있는 위치입니다.
   기존 copilot 폴더를 삭제하지 말고 폴더를 병합하며 같은 이름의 파일은 덮어씁니다.
   프로그램 폴더 안에 별도의 game-copilot-1.0.1 폴더를 만드는 방식이 아닙니다.
5. 평소 쓰던 run-free.cmd 또는 run-paid.cmd로 실행합니다.
6. 창 제목과 상단에 1.0.1이 표시되는지 확인합니다.

새 Python 설치, pip 설치, API 키 재입력은 필요하지 않습니다.

## API 키와 설정 보존

Windows 데이터 경로는 기존과 동일한 %APPDATA%\GameCopilot1 입니다.
free.key / paid.key / workspace.json / runtime.txt를 패치에 포함하지 않으며 덮어쓰지 않습니다.
.env와 .env.nvidia, .venv도 패치에 포함하지 않습니다.
키 저장 및 복호화를 담당하는 copilot/storage.py도 변경하지 않았습니다.
같은 PC와 Windows 계정에서 기존에 저장된 키와 프로필을 그대로 읽습니다.
환경변수로만 키를 쓰고 있었다면 기존 실행 환경도 유지해야 합니다.
다른 PC나 Windows 계정으로 옮기는 경우에는 암호화된 키 재사용을 보장하지 않습니다.

## 이번에 추가한 기능

- /v1/state의 선택 필드 capabilities: 실행 방식, 관측 전용, 장기 작업 지원, 작업 취소 지원.
- 정보가 없는 기존 v1 브리지는 미지정 모드로 기존 행동 흐름을 유지합니다.
- 데모는 턴제 연결임을 명시하고 연결 로그에 기능 정보를 표시합니다.
- 잘못된 타입/버전/상충하는 관측 전용 선언을 거절합니다.
- 실시간 연결은 이번 버전에서 관측과 조언만 지원합니다. 기존 단발 실행 경로로 보내지 않습니다.
- 행동 직전에도 관측 전용/실시간 변경 여부를 재확인합니다.

장기 작업/취소 지원 표시는 브리지가 선언한 능력입니다.
본체의 작업 시작/진행 관리/원격 취소는 아직 없고 실제 상용 게임 연결 모듈도 포함하지 않습니다.
다음 단계는 2번 작업 관리자입니다. 이번 패치에는 포함하지 않았습니다.

## API 없이 확인하기

1. 기존 프로필과 설정이 남아 있는지 확인합니다.
2. 데모 기지 → 연결 / 데모 초기화를 누릅니다.
3. 로그에 '연결 기능: 턴제'와 장기 작업/작업 취소 미지원이 나타나는지 확인합니다.
4. 데모 규칙 엔진 체크 → 자동 시작. 연구 10을 달성하고 멈추는지 확인합니다.
   외부 샘플 서버를 사용하면 서버도 종료 후 재시작해야 새 코드가 반영됩니다.

개발자 테스트: python -m unittest discover -s tests -v
검증 결과: 기존 29개 + 신규 9개 = 38개 통과. 실제 API 호출 없음.
기존 1.0.0에 패치를 덮어쓴 임시 설치본에서 키/설정 대용 파일의 바이트 보존과 데모 동작을 확인했습니다.
Windows GUI 실행과 실제 DPAPI 복호화, 실제 게임 연결은 이 환경에서 검증하지 못했습니다.

## 되돌리기

프로그램과 샘플 서버를 종료하고 백업한 프로그램 폴더로 실행합니다.
이번 패치는 데이터 형식을 바꾸지 않아 기존 사용자 데이터 폴더를 복원하거나 지울 필요가 없습니다.
PATCH_INFO.json에는 다음 패치를 위한 버전과 변경 파일 해시가 기록되어 있습니다.
단순 덮어쓰기 방식이므로 이 파일이 자동 설치나 버전 충돌 검사를 수행하지는 않습니다.
