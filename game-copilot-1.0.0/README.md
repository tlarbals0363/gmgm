# Game Copilot 1.0.3

3번 작업 취소·연결 끊김 패치입니다. 첨부된 2단계 완료본(내부 1.0.2)에만 적용합니다. `PATCH_3_README.md`를 먼저 읽으세요.
작업 ID, 접수/진행/결과/취소 의도를 관리하고 기존 단발 실행을 추적합니다. 세부 규격은 `TASK_MANAGER.md`에 있습니다.
실시간/관측 전용/장기 작업/취소 기능 선언을 읽고 표시하며 기존 v1 연결을 유지합니다.
지원 모듈의 원격 취소·유지 신호 만료 중지·읽기 전용 결과 확인을 추가했습니다. 규격은 `TASK_CANCEL_PROTOCOL.md`에 있습니다.
실시간으로 선언한 연결은 계속 조언 전용입니다. 4단계 이후 기능과 실제 게임 모드는 추가하지 않았습니다.

여러 게임을 나중에 연결하기 위한 **공통 데스크톱 본체**입니다. 이전 0.x와 별개입니다.
무료 NVIDIA / 유료 OpenAI 모드를 각각 실행합니다. 기존 키를 그대로 입력할 수 있습니다.
게임별 프로필·메모·판단 기록·모델 라우팅·조언·확인 실행·자동 실행·로그를 제공합니다.

## 이번에 실제로 되는 것과 안 되는 것

- 내장 데모: API 없이도 관측 → 판단 → 행동 → 승리까지 작동.
- 같은 데모에서 NVIDIA/OpenAI 실제 API를 이용한 판단 가능(키와 모델 접근 권한 필요).
- 로컬 HTTP 게임 브리지 연결 규격과 작동하는 샘플 서버 포함.
- **문명·림월드·롤체 등 실제 게임용 연결 모드는 아직 없습니다.** 게임마다 별도 개발·검증이 필요합니다.
- **화면 캡처, 마우스/키보드 조작, 전역 단축키, 인터넷 목표 검색은 이번 버전에 없습니다.**
  이번 버전은 이전 화면 조작판의 대체 패치가 아니라, 구조화된 게임 상태 기반의 새 본체입니다.
- 게임 이름만 입력한다고 게임 내부 상태에 접근할 수는 없습니다.
- 온라인 게임은 게임사 약관과 허용 API 범위에서만 연결하세요. 안티치트 우회 기능은 없습니다.

## VS Code에서 실행

1. 내부 버전 1.0.2인 첨부본에 PATCH_3_README.md대로 덮어쓰세요. 0.x나 다른 단계의 설치본에는 적용하지 마세요.
2. VS Code → 폴더 열기 → `game-copilot-1.0.0` 선택.
3. 터미널 → 새 터미널 → 아래 중 하나를 입력합니다.

무료 NVIDIA:
```powershell
powershell -ExecutionPolicy Bypass -File .\run-free.ps1
```

유료 OpenAI:
```powershell
powershell -ExecutionPolicy Bypass -File .\run-paid.ps1
```

두 모드는 같은 본체와 프로필을 사용하지만 키와 모델 설정은 구분됩니다.
동시에 두 창을 실행하지 못하도록 잠금 처리했습니다. 실행 중인 창을 먼저 닫고 전환하세요.
Python 3.10 이상 + Tcl/Tk가 필요합니다. **pip 패키지 설치와 Qt 설치는 필요하지 않습니다.**
기존 Python이 잘 작동한다면 새 가상환경도 필요하지 않습니다.

설치 점검만 하려면:
```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

Python을 못 찾거나 Tcl/Tk 오류가 나면 기존에 사용하던 실행 파일을 직접 지정할 수 있습니다:
```powershell
powershell -ExecutionPolicy Bypass -File .\run-free.ps1 -PythonExe "C:\Users\tlarb\Desktop\tlarbals\game-copilot-v0.1.0\.venv\Scripts\python.exe"
```
위 경로의 실행 파일이 실제로 존재하는지 확인하세요. **`.venv` 폴더를 새 폴더로 복사하지 마세요.**
선택된 Python 경로는 기억합니다. 원래 Python 폴더를 삭제/이동하면 다시 지정해야 합니다.
Anaconda도 Tk가 정상이라면 쓸 수 있지만 모든 환경에서 작동을 보장하지는 않습니다.
필요하면 https://www.python.org/downloads/windows/ 에서 Tcl/Tk를 포함하여 Python을 설치하세요.

## 첫 테스트 (API 없이)

1. `데모 기지` 프로필을 선택합니다.
2. `연결 / 데모 초기화`를 누릅니다.
3. `데모 규칙 엔진` 체크를 유지하고 `자동 시작`을 누릅니다.
4. 식량/연구/턴이 바뀌며 6번 행동 후 승리하고 멈추는지 확인합니다.

이것은 공통 관측·실행 루프 테스트이며 AI 모델 성능을 보여주는 데모는 아닙니다.
다시 연결하면 내장 데모는 처음부터 시작됩니다.

## 기존 API 키 사용

`모델 / API 키` 탭 → 키 입력 → `설정 / 입력한 키 저장`.
`Bearer `를 포함하여 붙여넣으면 그 부분은 제거합니다. 따옴표 없이 키만 입력하세요.
그다음 `빠른 모델 시험`과 `심화 모델 시험`을 각각 누릅니다. 소량의 API 사용량이 발생합니다.

- NVIDIA 키는 무료 실행에서, OpenAI 키는 유료 실행에서 사용합니다. 서로 호환되지 않습니다.
- 같은 제공자에서 모델을 바꿀 때는 보통 기존 키를 사용하며 모델 접근 권한/한도는 별개입니다.
- 키 발급: https://build.nvidia.com/ / https://platform.openai.com/api-keys
- 이전 키가 `.env` / `.env.nvidia`에 있다면 `이전 폴더에서 키 가져오기`로 그 파일의 폴더를 선택하세요.
  먼저 `%APPDATA%\GameCopilot`을 확인하고, 없다면 이전 프로그램 폴더를 선택하세요.
- 원본 설정은 수정하지 않습니다. 이전 프로필 형식은 자동 이전하지 않습니다.
- Windows에서는 현재 사용자 계정의 DPAPI로 키를 암호화 저장합니다. 다음 실행 때 다시 입력할 필요 없습니다.
- 환경변수 `NVIDIA_API_KEY` / `OPENAI_API_KEY`도 지원합니다. 저장된 키가 있으면 우선합니다.
- Windows 이외에서는 환경변수를 사용하세요. 키 영구 저장은 Windows 전용입니다.

API를 시험한 뒤 `게임 / 코치`로 돌아와 **데모 규칙 엔진 체크를 끄면 실제 모델이 판단**합니다.
무료 엔드포인트는 제공자 계정 한도/정책에 따릅니다. 영구·무제한 무료가 아닙니다.
유료는 OpenAI API 사용료가 따로 발생하며 ChatGPT 구독에 포함된다고 가정하지 마세요.
무료 실패 시 유료로 자동 전환하지 않습니다.

## 빠른 판단 / 심화 판단

평소 빠른 모델 1회 → 심화 요청 또는 신뢰도 0.65 미만일 때 심화 모델 최대 1회.
심화 호출 직전에 다시 상태를 읽습니다. 분석 한 번에 최대 2회의 API 요청입니다.
기본 시간 제한은 빠른 30초, 심화 60초이며 연속이면 약 90초와 연결 시간이 걸릴 수 있습니다.
**항상 빠르게 반응하는 시스템은 아니며, 실시간 액션 게임을 보장하지 않습니다.**
턴제/일시정지 가능한 게임에 먼저 연결하는 것을 권합니다.

심화를 꺼둔 상태에서 심화가 필요하면 행동은 보류합니다. 응답 오류/초과에는 자동 재시도하지 않습니다.
중지하거나 제한시간을 넘기면 늦게 도착한 응답은 폐기합니다. 이전 네트워크 요청이 끝날 때까지 중복 API 요청도 막습니다.
이미 서버에 전송한 API 요청은 중지 후에도 과금될 수 있습니다.

자동은 낮은 위험·모델 추정 신뢰도 0.8 이상·심화 필요 없음일 때만 행동합니다.
**신뢰도 수치는 실제 정확도 보증이 아닙니다.** 수동 확인 실행부터 시험하세요.
행동 전 revision과 후보 목록을 재확인하고 90초 이상 지난 관측은 사용하지 않습니다.
시간 제한만 크게 늘리면 행동이 오래되어 거절될 수 있습니다.
실행 확인을 받지 못한 행동은 자동 재전송하지 않습니다. 게임 상태를 직접 확인하세요.

중지 버튼과 이 창의 Esc는 이후 행동을 차단합니다. 이미 전달/실행된 게임 행동은 되돌리지 못합니다.
Esc는 전역 단축키가 아닙니다. 게임 창에 포커스가 있으면 본체의 중지 버튼을 사용하세요.

## 프로필과 기억

게임별 이름 / 연결 설정 / 목표 / 직접 작성한 메모 / 최근 판단 30개를 저장합니다.
최근 판단 중 8개와 메모를 다음 모델 입력에 포함합니다. 모델 가중치를 학습하는 기능은 아닙니다.
모델이 쓴 메모는 검증되지 않은 관찰/추정으로 구분하며, 잘못된 기억은 workspace.json의 history에서 지울 수 있습니다(프로그램 종료 후).
프로필 이름 변경·삭제·최근 삭제 복원 버튼이 있습니다. 삭제는 휴지통 이동입니다.
`목표 안내 생성`은 빠른 모델의 사전지식 답변이며 검색이 아닙니다. 확인 후 목표 입력란에 반영하세요.
특정 상용 게임의 내장 목표 문구를 넣지 않았습니다.

데이터: `%APPDATA%\GameCopilot1` (폴더를 바꿔 설치해도 같은 데이터 사용).
Windows가 아닌 환경은 `~/.config/GameCopilot1`입니다.
업데이트 시 프로그램 소스만 교체하고 이 데이터 폴더는 보존하세요. 키 파일은 다른 PC/계정으로 복사해도 해독되지 않을 수 있습니다.
게임 상태·목표·메모·최근 판단이 선택한 API로 전송됩니다. API 키 자체는 인증 헤더에만 사용됩니다.
브리지 토큰은 로컬 workspace.json에 저장되며 API 입력에 포함하지 않습니다.

## 새 게임 연결과 개발

`ADAPTER_PROTOCOL.md`를 읽고 게임별 모드/외부 브리지를 개발합니다. 게임에 따라 개발 난도는 크게 다릅니다.
본체가 요구하는 것은 상태 JSON과 유한한 행동 후보 목록입니다. 임의 코드 실행 도구를 모델에 주지 않습니다.
상태만 읽을 수 있는 연결은 `can_act: false`로 조언 전용으로 사용할 수 있습니다.
샘플: `python .\examples\demo_bridge.py` (내장 데모와 같은 규칙의 외부 서버).
테스트: `python -m unittest discover -s tests -v`
